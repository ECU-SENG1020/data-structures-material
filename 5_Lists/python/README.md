Hands-on exercise: Build a custom linked list

This exercise guides students through implementing a custom singly-linked list in Python (or another language of your choice). The goal is to learn how linked lists work by building common list operations from scratch.

Learning objectives
- Understand the node/list structure used in a linked list
- Implement common list operations without using built-in list types
- Practice indexing, iteration, and in-place modifications on a linked data structure

Required features (implement, test, and demonstrate each):

1. Create a list
	- Construct an empty linked list and optionally initialize it from an iterable

2. Append
	- Add a new element to the end of the list

3. Print a list
	- Provide a human-readable representation (for example, as a string) that shows the sequence of values

4. Length
	- Return the number of elements stored in the list

5. Retrieve by index
	- Allow retrieving an element by zero-based index (raise an appropriate error for out-of-range indexes)

6. Set by index
	- Update the value at a given index

7. Delete by index
	- Remove the node at a given index and maintain list integrity

8. Use list in a loop
	- Make the list iterable so it can be used in for-loops

9. Add (concatenate / plus)
	- Support adding two lists together to produce a new list that contains elements from both

10. Extend
	- Extend the list in-place with elements from an iterable or another list

11. Implement the IN capability
	- Support membership testing (value in list) using an efficient traversal

12. Clear
	- Remove all elements from the list, leaving it empty

13. Remove
	- Remove the first occurrence of a value from the list (raise an error if not found or return a status)

14. Insert after
	- Insert a new value after a given node or after the first occurrence of a target value

15. Prepend
	- Add a new element at the start of the list

16. Sort
	- Provide a method to sort the list in-place
