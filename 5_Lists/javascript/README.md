Hands-on exercise: Build a custom linked list (JavaScript)

This folder mirrors the Python implementation in `../python`, but uses plain JavaScript (Node.js) to demonstrate a singly-linked list built from scratch.

Files
- `NodeModule.js`: Node class (`data`, `next`)
- `ListModule.js`: `DsList` singly-linked list
- `app.js`: small demo using the list
- `demo_node.js`: small demo using raw nodes
- `unit_tests.js`: tiny test runner

Run
- Demo: `node app.js`
- Node demo: `node demo_node.js`
- Tests: `node unit_tests.js`
