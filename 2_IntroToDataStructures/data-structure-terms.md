### **Structural Classification**
- **Linear**: Data is arranged in a sequential order (e.g., arrays, linked lists).
- **Non-Linear**: Data is organized in a hierarchical or interconnected manner (e.g., trees, graphs).

### **Data Type Classification**
- **Homogeneous**: All elements are of the same data type (e.g., array of integers).
- **Heterogeneous**: Elements can be of different data types (e.g., Python lists, structs).

### **Indexing**
- **Indexed**: Each element can be accessed using an index (e.g., arrays, lists).
- **Unindexed**: Elements are accessed without a specific index (e.g., sets, queues).

### **Ordering**
- **Ordered**: Elements maintain a specific sequence (e.g., lists, tuples).
- **Unordered**: No guaranteed order of elements (e.g., sets, hash tables).

### **Mutability**
- **Mutable**: Elements can be changed after creation (e.g., lists, dictionaries).
- **Immutable**: Elements cannot be changed once created (e.g., tuples, strings).

### **Resizability**
- **Dynamic**: Number of elements can increase or decrease (e.g., lists, sets).
- **Static**: Number of elements cannot be changed (e.g., tuples, arrays).

### **Uniqueness**
- **Unique**: No duplicate elements allowed (e.g., sets, keys in dictionaries).
- **Duplicates**: Duplicate elements are allowed (e.g., lists, arrays).

### **Key Constraints**
- **Unique Keys**: Each key is distinct (e.g., dictionary keys).
- **Duplicate Keys**: Not typically allowed in standard data structures, but some specialized structures (like multi-maps) support them.

### **Complexity**
- **Time Complexity**: Measures the time an algorithm takes to run as a function of input size.
- **Space Complexity**: Measures the amount of memory an algorithm uses relative to input size.
