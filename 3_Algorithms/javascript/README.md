# Algorithms (JavaScript)

This folder mirrors the Python demos in `3_Algorithms/python`, but written in beginner-friendly JavaScript.

## Run
From this folder:
- `node 1_efficiency.js`
- `node 2_linear_search.js`
- `node 3_binary_search.js`
- `node 4_indexed_search.js`
- `node 5_recursion.js`
- `node 6_selection_sort.js`
- `node 7_insertion_sort.js`
- `node 8_merge_sort.js`
- `node problem_solving_strategies.js`

## Notes
- This folder uses ES Modules (`import`/`export`). See `package.json`.
