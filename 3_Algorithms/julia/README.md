# Algorithms (Julia)

This folder mirrors the Python demos in `3_Algorithms/python`, but written in beginner-friendly Julia.

## Run
From this folder:
- `julia 1_efficiency.jl`
- `julia 2_linear_search.jl`
- `julia 3_binary_search.jl`
- `julia 4_indexed_search.jl`
- `julia 5_recursion.jl`
- `julia 6_selection_sort.jl`
- `julia 7_insertion_sort.jl`
- `julia 8_merge_sort.jl`
- `julia problem_solving_strategies.jl`

## Notes
- Julia uses **1-based indexing**.
- Functions ending in `!` usually modify (mutate) an argument.
