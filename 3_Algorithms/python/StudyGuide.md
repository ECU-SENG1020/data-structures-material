
# Algorithms Study Guide

- understand linear search
    - be able to recognize a linear search
    - be able to create a linear search
    - know its time complexity (Big-O)
- understand binary search
    - be able to recognize a binary search
    - be able to create a binary search
    - know its time complexity (Big-O)
- understand basics of a recursive function
    - be able to recognize a recursive algorithm
    - understand the base case
    - understand the challenge of using a recursive function on data with deep levels 
- understand selection sort
    - be able to recognize a selection sort
    - be able to create a selection sort
    - know its time complexity (Big-O)
- understand the time complexities (Big-O) covered in class
    - be able to rank them in order of time complexity
    - be able to state the time complexity of a given code snippet
